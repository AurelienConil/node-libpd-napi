# Répertoire lib

Historique: ce dossier contenait des bibliothèques partagées précompilées (libpd.dylib/.so/.dll).
Ce n’est plus nécessaire: libpd est maintenant liée statiquement dans le binaire `.node`.

Vous pouvez utiliser ce dossier pour stocker de la documentation ou des artefacts liés au build si besoin, mais aucune copie de bibliothèque dynamique n’est requise au runtime.
